R Role (บทบาท)

กำหนดบทบาทผู้เชี่ยวชาญ

ระบุตำแหน่งและระดับความเชี่ยวชาญให้ AI สวมบทบาทตรงตามสายงาน เช่น "ผู้เชี่ยวชาญด้านการวิเคราะห์การเงิน" หรือ "ผู้เชี่ยวชาญด้านการจัดซื้อและซัพพลายเชน"

เชื่อมโยงตาราง: Department + Job Level
T Task (คำสั่งงาน)

ระบุภารกิจและเป้าหมายชัดเจน

ใช้คำกริยาที่ชัดเจน เช่น วิเคราะห์ (Analyze), สรุป (Summarize), เปรียบเทียบ (Compare), ร่างเอกสาร (Draft) พร้อมเป้าหมายทางธุรกิจ

เชื่อมโยงตาราง: Prompt Template + Business Objective
C Context (บริบทข้อมูล)

ป้อนข้อมูลนำเข้าจริงของงาน

แนบข้อมูลประกอบตามช่อง Input Required เช่น ข้อมูลยอดขายราย SKU, Dashboard KPI, งบประมาณ หรือข้อมูลคู่ค้า

เชื่อมโยงตาราง: Input Required + Process
F Format & KPI

กำหนดรูปแบบและเกณฑ์วัดผล

กำหนดโครงสร้างผลลัพธ์ (ตารางเปรียบเทียบ, Bullet Points, รายงานผู้บริหาร) และเน้นให้ตอบโจทย์ KPI ของงานนั้นๆ

เชื่อมโยงตาราง: Output Expected + KPI

เปรียบเทียบ Before vs After: ยกระดับคำสั่งจากคลังองค์กร

ข้อควรปฏิบัติความปลอดภัยข้อมูลองค์กร (Enterprise AI Governance)

1. ใช้งานผ่านบัญชี Microsoft Copilot (Commercial Data Protection) ของบริษัทเท่านั้น
2. หลีกเลี่ยงการวางข้อมูลส่วนบุคคลที่อ่อนไหว (PDPA เช่น เลขบัตรประชาชน เงินเดือนรายบุคคล) หรือรหัสผ่านลงใน Prompt โดยตรง
3. ตรวจสอบความถูกต้องของตัวเลขและข้อกฎหมาย (Human-in-the-Loop) ทุกครั้งก่อนนำไปใช้งานจริง
